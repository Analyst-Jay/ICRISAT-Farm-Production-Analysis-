# ICRISAT Farm Production Analysis

## Project Overview

This project uses Microsoft Excel to analyse agricultural production data from ICRISAT, focusing on five crops: rice, cotton, oilseed, maize, and sorghum. then proceeding to Microsoft Power BI for visualization.

The analysis explores how crop production varies across Indian states and districts and how production changes over time. The dashboard presents regional comparisons, production trends, and key agricultural metrics to support exploratory analysis.

## Project Objectives

- Analyse the production of selected crops across India.
- Compare crop production between states and districts.
- Examine production trends over time.
- Identify leading production regions for each crop.
- Explore changes and fluctuations in agricultural production.
- Present findings through interactive Power BI visualisations.

## Dataset

The analysis uses agricultural data with fields including:

| Field | Description |
|---|---|
| Year | Year associated with the production record |
| State | Indian state |
| District | District within the state |
| Crop | Crop being analysed |
| Production | Recorded crop production |
| Area | Cultivated area, where available |

## Dashboard Analysis

The analysis is organised around three proposed analytical areas:

### 1. Agricultural Overview

Provides a high-level view of crop production across the selected crops.

The overview supports comparisons of total production and the contribution of different crops to overall production.

### 2. Regional Productivity

Examines the distribution of crop production across states and districts.

This analysis helps identify leading production regions and compare regional contributions for the selected crops.

### 3. Production Trends and Stability

Explores changes in crop production over time.

The analysis focuses on year-to-year changes, fluctuations, and production patterns across rice, cotton, oilseed, maize, and sorghum.

## Key Findings

The following observations were identified during the analysis:

- **Rice:** Recorded approximately 3.63 million tons of production. Uttar Pradesh led with approximately 510,000 tons, followed by West Bengal at approximately 450,000 tons.
- **Cotton:** Recorded approximately 116,720 tons. Meerut and Muzaffarnagar were among the leading districts, with approximately 65,000 and 62,000 tons respectively.
- **Sorghum:** Recorded approximately 459,540 tons, with Madhya Pradesh contributing approximately 202,000 tons.
- **Production trends:** Rice showed an upward trend in the analysed period, while oilseed and maize production fluctuated and declined sharply near the end of the timeline.

The sharp declines near the end of the timeline should be interpreted carefully. The final-year data may be incomplete, so the decline should be verified before drawing conclusions.

- Count of distincts

These measures support comparisons of production volume, regional contribution, changes over time, and stability.

## Data Considerations

The analysis is based on the available dataset and its recorded production values. Comparisons depend on the completeness and consistency of the source data.

In particular, the apparent decline in some crops near the end of the timeline may be affected by incomplete final-year records. This should be validated before interpreting the change as a real production decline.

## Conclusion

The ICRISAT Farm Analysis project demonstrates how Power BI can be used to explore agricultural production across crops and regions.

By examining production volumes, regional contributions, and historical trends, the project provides a structured view of the selected crops and highlights patterns that can be investigated further.
